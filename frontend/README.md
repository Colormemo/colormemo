# Фронтенд

Vite + React + TypeScript. Запуск описан в README в корне репозитория.

## Что уже сделано

- каркас приложения и выбор уровня сложности;
- модуль запросов `src/api/` с переключателем на заглушки;
- заглушки API в `src/api/mock.ts` — полный цикл игры работает без сервера;
- рабочий экран игры «Повтори цвет» (`src/games/ColorRecall.tsx`) как образец.

## Что делать дальше (Маша)

1. **«Выбери цвет»** — по образцу `ColorRecall.tsx`: показать цвет, спрятать,
   показать варианты из `task.options`, отправить выбранный.
2. **«Воспроизведи последовательность»** — показ по одному цвету с интервалом
   `showTimeMs`, затем сборка порядка (перетаскивание или нажатия по очереди).
3. **Экраны вне игры**: главная, выбор игры, профиль, статистика — после макетов.
4. **Маршрутизация.** На GitHub Pages у обычного роутера ломаются вложенные
   адреса при перезагрузке страницы. Варианты: `HashRouter` (адреса вида
   `/#/games/recall`, работает сразу) либо `BrowserRouter` с `basename`
   плюс копия `index.html` в `404.html` — её уже делает workflow публикации.

## Важное про игровую логику

- Время отсчитывать через `performance.now()`, а не `Date.now()`: не сбивается,
  если у игрока подвинулись системные часы.
- Все таймеры складывать в `useRef` и чистить в `useEffect`, иначе при быстром
  выходе из игры они продолжат работать и состояние поедет.
- Параметры уровней — только в `packages/shared/src/difficulty.ts`.
- После правок в общем пакете запускать `npm run build:shared`,
  иначе фронт подхватит старую версию.
