# Бэкенд

Express + Prisma + PostgreSQL. Запуск описан в README в корне репозитория.

## Из чего состоит

```
src/
├── app.ts            сборка приложения: ручки, раздача фронта, обработка ошибок
├── server.ts         запуск, выбор хранилища
├── env.ts            настройки в одном месте
├── auth/             пароли (scrypt), токен сессии (HMAC), ручки входа
├── games/            генерация заданий, проверка ответов, хранилища
└── stats/            агрегаты статистики и история прохождений
```

Ручки:

| Метод и адрес             | Что делает                          | Нужен вход |
| ------------------------- | ----------------------------------- | ---------- |
| `GET /api/health`         | Проверка, что сервер жив            | нет        |
| `POST /api/auth/register` | Регистрация, сразу открывает сессию | нет        |
| `POST /api/auth/login`    | Вход                                | нет        |
| `POST /api/auth/logout`   | Выход                               | нет        |
| `GET /api/auth/me`        | Кто сейчас вошёл                    | да         |
| `POST /api/games/task`    | Новое задание                       | нет        |
| `POST /api/games/answer`  | Проверка ответа, подсчёт очков      | нет        |
| `GET /api/stats`          | Сводная статистика игрока           | да         |
| `GET /api/stats/history`  | Последние попытки                   | да         |

Играть можно без аккаунта: задание выдаётся, очки считаются, но `userId`
остаётся `null`, и в статистику попытка не попадает.

## Два хранилища, один интерфейс

`src/games/repository.ts` описывает, что хранилище умеет, а не как оно устроено.
Реализаций две:

- `prisma.repository.ts` — PostgreSQL, рабочий вариант;
- `memory.repository.ts` — в памяти процесса, с необязательной записью в файл.

Что это даёт:

- тесты поднимают настоящее приложение Express, но с хранилищем в памяти, —
  значит Postgres не нужен ни локально, ни в CI;
- `npm run dev:nodb` запускает приложение целиком там, где базы нет;
- при правках схемы меняется один файл, а не игровая логика.

## Правила, о которых легко забыть

- **Очки считает сервер** по сохранённому у себя заданию. Клиент присылает
  только свой ответ. Иначе результат подменяется через консоль браузера.
- **Порядок в `app.ts`**: сначала ручки `/api`, потом раздача статики.
  Наоборот — и запрос к API вернёт `index.html`.
- **Всё, что пришло от клиента**, разбирается через zod, включая уровень
  сложности: верхняя граница держится по `MAX_DIFFICULTY`.
- **Пароль не хранится и не логируется** — только результат scrypt.

## Полезное

```bash
npm run dev          # с базой
npm run dev:nodb     # без базы, данные в .data/colormemo.json
npm test             # 44 теста ручек API

npx prisma migrate dev --name что_поменяли   # создать миграцию
npx prisma migrate deploy                    # применить готовые
npx prisma studio                            # посмотреть данные
npx prisma db seed                           # заполнить справочник игр
```
