# Бэкенд

NestJS + Prisma + PostgreSQL. Запуск описан в README в корне репозитория.

## Что уже сделано

- каркас приложения, CORS, валидация входящих данных, автодокументация Swagger;
- схема базы: `User`, `Game`, `GameTask`, `Result` (`prisma/schema.prisma`);
- ручки игр: `POST /api/games/task` и `POST /api/games/answer`;
- проверка ответов и подсчёт очков через общий пакет `@colormemo/shared`.

## Что делать дальше (Настя)

1. **Уточнить схему базы** под лабу 2: полный список данных пользователя, игры,
   задания, попытки и результата. Текущая схема — рабочая основа, не догма.
2. **AuthModule**: регистрация, вход, выход, текущий пользователь.
   Типы запросов и ответов уже описаны в `packages/shared/src/api.ts`.
   - пароли хешировать через `argon2` (уже в зависимостях), сам пароль не хранить;
   - токен JWT класть в httpOnly cookie, а не в localStorage;
   - локально `sameSite: 'lax'`, на проде (разные домены) `sameSite: 'none', secure: true`.
3. **StatsModule**: статистика по играм и прогресс, тип ответа `StatsResponse`.
4. **Привязать userId**: в `games.controller.ts` он пока жёстко `null`,
   то есть все играют как гости. После авторизации брать его из токена.

## Полезное

```bash
npx prisma migrate dev --name что_поменяли   # создать миграцию
npx prisma studio                            # посмотреть данные
npx prisma db seed                           # заполнить справочник игр
```

Документация API поднимается вместе с сервером: http://localhost:3000/api/docs
